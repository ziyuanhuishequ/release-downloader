GitHub Release 下载整理工具 v1.6.1
==================================

单文件程序，免安装。双击运行，不写注册表、不装依赖，整个文件夹拷走即可用。

本版新增：断点续传、下载完成后的「打开文件夹」提醒、
下载卡顿时的自动换线路（含界面提示）、进度条下方显示总速度。


一、怎么用
----------
1. 双击「GitHub下载整理工具.exe」，直接弹出程序窗口（不经过浏览器）。
2. 在「仓库地址」里填仓库，一行一个，下面几种写法都认：
       microsoft/PowerToys
       https://github.com/sharkdp/bat
       https://github.com/sharkdp/bat/releases
       git@github.com:sharkdp/bat.git
3. 点「扫描 Release」（右下角橙色大按钮）。默认勾选「只取最新版本」，
   取消勾选则列出全部历史版本；改动勾选后会自动重新扫描。
4. 扫描完自动开始测速（几秒），右上角显示实测最快线路；
   点那个线路标签，可以展开看全部线路的速度。
5. 在文件列表里勾选需要的文件（「仅 Windows」「仅 macOS」「全选」可快速筛选），
   点底部「开始下载」。
6. 下载中每一行都会显示像素进度条、百分比和实时速度；
   点「停止」随时中断，已下载部分保留，下次接着下。


二、断点续传（没下完下次接着下）
--------------------------------
下载没完成（点停止、断网、直接关窗口、蓝屏断电都算），已经下好的那部分
会留在目标文件夹里，不会白下。下次接着下的三种方式：

  · 重新打开软件时，文件列表上方会自动出现一条黄色提示：
        「有 N 个文件上次没下完 · 已下 386 MB / 1.2 GB（32%）」
    点「继续下载」，程序会列出这些文件并从断点接着下；
    点「删除断点」则丢掉这些半成品，下次从头开始。
  · 不想续传就直接点「继续下载」右边的空白处，提示条会随任务开始消失。
  · 同一次运行里点了「停止」再点「开始下载」，也会自动从断点续传，
    列表里那一行的状态会先显示「可续传 62%」。

续传时只下剩下的部分，控制台状态会写「其中 N 个从断点续传（已下 xx MB）」。
每个未完成文件旁边会有一个 <文件名>.part.meta 小文件记录来源地址与大小，
下载完成后自动删除，不会残留。

需要注意：文件名（含版本号）变了就当成新文件，不会接到旧断点上；
换了保存目录也认不到原来的断点，请在同一个目录里继续。


三、下载完成后的提醒
--------------------
选中的文件全部下完（或全部处理完）后，窗口中间会弹出提示框：

    全部下载完成
    3 个文件都已下好，断点记录已自动清理。
    保存位置  C:\Users\你\Desktop\PowerToys\Windows
    现在打开这个文件夹看看吗？
    [打开文件夹]  [稍后，我自己去]

点「打开文件夹」直接跳转到保存目录；点「稍后」或窗口里任意空白处关闭，
按 Esc 也是关闭，按回车等同「打开文件夹」。
有文件失败时标题会变成「下载完成（有文件失败）」，并写明成功/失败数量，
失败文件的断点会保留，可以再点一次「开始下载」重试。


四、两个勾选项是什么意思
------------------------
把鼠标停在文字上约 0.3 秒，会弹出说明卡片，移开就收起来。

「只取最新版本」
    只保留每个仓库最新那一个 Release 里的文件，忽略历史版本。
    想回退到旧版时，取消勾选即可列出全部版本。

「包含 Pre-release」
    Pre-release（预发布版）是作者主动标记的测试版，常见后缀有
    beta / rc / alpha / nightly / dev。
    勾选：测试版也列出来，功能最新，但可能崩溃、可能有破坏性改动。
    取消：只保留正式稳定版，日常使用建议取消勾选。
    作者在发布页勾了「Set as a pre-release」，这个版本就会出现在这里。


五、Token 怎么获取（可选）
--------------------------
Token 是 GitHub 的个人访问令牌。不填也能用，只是未登录状态下每小时只有
60 次请求，仓库填得多、反复扫描时会报 403 被限流；填了额度提到 5000 次/小时，
私有仓库也必须填。把鼠标停在「Token」三个字上能看到完整步骤。

1 打开 github.com，登录后点右上角头像 → Settings
2 左侧菜单拉到最底 → Developer settings
3 Personal access tokens → Tokens (classic)
4 点 Generate new token (classic)
5 权限勾选 public_repo 就够（要读私有仓库再加 repo）
6 页面底部点 Generate token，复制 ghp_ 开头那串，粘贴到 Token 输入框

令牌只完整显示一次，记得先存好；怀疑泄露可在同一页面点 Revoke 作废重发。


六、文件会存到哪里
------------------
默认存到「桌面」，并按下面的结构自动建文件夹：

    桌面/
        仓库名/
            Windows/    .exe .msi .msix .appx
            macOS/      .dmg .pkg
            Others/     其他平台（Linux 包、源码包等）

文件名统一为：仓库名-版本-平台-架构-原文件名
例如：bat-v0.26.1-Windows-x64-bat-v0.26.1-x86_64-pc-windows-msvc.zip
（原文件名里已经有的信息不会重复拼接）

想换位置：点「保存到」右边的「浏览…」选一个文件夹，或直接改输入框里的路径；
「打开目录」会跳到该文件夹。


七、关于下载速度（大文件为什么会「停一会儿又飞快」）
----------------------------------------------------
程序内置自动测速，会同时测试直连和多个 GitHub 加速镜像，按实测速度排序，
下载时优先用最快的那条；某条线路半路断了会自动换下一条继续下。

单个文件还会自动多线程分片下载（按体积切 4~8 段同时拉），
在网络对单连接限速的情况下，实测比单线程快 2~4 倍，不需要任何代理工具。
分片下载同样支持续传：中断后再开始，每段都从自己停下的位置继续。

【正常现象：进度停住一会儿】
下大文件时，进度条可能突然停住十几秒不动，然后一下子蹿一截。这不是卡死，
也不是程序出问题，原因有三类：

  1. GitHub 对单条连接限速。8 条连接一起下时，某一条被压到只剩几十 KB/s，
     它那一段就几乎不动；其余 7 段下完后，只剩它一个在慢慢爬，整体进度
     看起来就「停住了」。等它下完或换到新连接，速度立刻恢复，进度就猛跳一截。
  2. 连接被中间链路挂住（半开连接）。数据不来了，但连接没报错，
     客户端只能等超时。
  3. 磁盘写入被占用（杀毒软件扫描下载中的安装包时最常见）。

【程序怎么处理】
  · 10 秒内没明显进展的连接，直接断开换一条重连，从断点接着下，不重下已下部分；
  · 某一段的速度不到其他段的三分之一时，主动踢掉它换连接，避免一条慢线拖累全程；
  · 单次连接的「整体时长限制」已取消，只保留「15 秒没收到数据就重连」，
    慢速但正常的连接不会再被误杀（老版本正是这里导致大文件反复卡住）。
所以看到卡住，什么都不用做，程序会自己换线恢复，一般 5~15 秒。

【界面上的提示】
  · 进度条下方小字：「总速度 3.2 MB/s」实时显示所有文件加起来的速度；
    卡住时变成珊瑚色的「总速度 0 B/s · 正在换线路」；
  · 底部中间状态行：卡顿时显示「连接卡顿，正在自动重连（约 5~15 秒），请稍候」；
  · 文件列表状态列：该行速度显示为珊瑚色的「换线路中…」，鼠标停上去有详细说明。

线路仅供参考，可用性会随时间变化：程序每次启动都会重新测，只把能用的排在前面。


八、界面说明
------------
窗口从上到下分五块：
  顶部      图标 + 标题，右侧是当前最快线路和版本号（点线路标签看详情）
  仓库地址  填仓库、选筛选条件、填 Token、点「扫描 Release」
  续传提示  只在有未完成任务时出现（黄色条，带「继续下载」按钮）
  文件列表  勾选要下的文件，右侧一排按钮做批量选择 / 重新测速
  底部      整体进度条 + 总速度（进度条下方小字）+ 完成数量 + 「开始下载」或「停止」

整界面是像素画风：米色底、墨蓝描边、珊瑚色按钮，进度条是分段像素块。
带虚线下划线的文字（如「Token」）表示可以悬停查看说明。


九、下载开始时的小卡片
----------------------
点「开始下载」后，右下角会浮出一张小卡片，8 秒后自动收起，也可以点右上角 ×
提前关闭。卡片上有两个按钮：

  「领取积分」      打开 AI 工具制作页（本软件就是用这个工具免费做出来的，
                    每天可领 5000 积分，同款工具自己也能做）
  「更多黑科技内容」 打开 sucaizy.com 素材资源站

不点也没关系，不影响下载，卡片自己会走。


十、常见问题
------------
1) 首次运行弹 "Windows 已保护你的电脑"
   程序没有购买数字签名证书，属于正常现象。点「更多信息」→「仍要运行」。

2) 杀软提示未知文件
   同理，未签名的 exe 容易被标为「未知发布者」。添加信任即可。

3) 扫描报错 403 或提示频率受限
   填一个 GitHub Token（只需 public_repo 权限），私有仓库也必须填 Token。

4) 某个文件一直失败
   列表里那一行会标红并写明原因（404 / 403 / 网络错误），其他文件不受影响。

5) 想下别的架构（arm64 等）
   扫描结果里本来就包含所有 asset，需要哪个勾哪个，程序不做过滤。

6) 窗口太窄看不全
   窗口可以拖动放大；文件列表里的文件名支持鼠标悬停查看完整保存路径与来源。

7) 说明卡片没弹出来
   需要在文字上停住约 0.3 秒（不是划过），移开就会收起。

8) 重开软件没看到续传提示
   断点只在原保存目录里找。看一下「保存到」是不是原来那个文件夹；
   或者那个任务其实已经下完（下完会自动清理断点）。

9) 下载大文件时进度停住不动，是不是卡死了
   不是。多数是某一条连接被 GitHub 限速或挂住了，剩下那一段在慢慢爬。
   程序在 10 秒内没进展就会自动断开换线路，从断点接着下，一般 5~15 秒恢复。
   看到「换线路中…」「正在自动重连」就是它在自己处理，不需要点停止，
   也不需要重开软件。详见第七节。

10) 大文件最后一点总是很慢
   分片下载时，最后收尾常常只剩一两条连接在跑，速度会掉下来。
   程序会把明显偏慢的那条踢掉重连，通常能把尾巴的时间砍掉一大截。
   如果全程都只有几十 KB/s，那是你的宽带或线路本身的问题，
   可以点「重新测速」换一条线路试试。


十一、说明
----------
本程序只做两件事：把指定仓库的 Release 文件下载下来、按系统分类放好。
不会修改、重新打包任何安装包，也不会在解压或运行时跳转任何网站。
请仅用于下载你有权使用的软件，遵守对应项目的许可协议。
