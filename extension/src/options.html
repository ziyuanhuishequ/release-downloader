下载加速

GitHub Token 可选

不填也能用，但 GitHub 匿名接口每小时只有 60 次，扫描多了会返回 403。 填一个只读的 Personal Access Token（public_repo 或无任何勾选即可）能提到 5000 次/小时， 也能读到你自己的私有仓库。

Token 存在 chrome.storage.local，不会上传到任何服务器。

线路池 可动态更新

线路池是仓库里的 routes.json，扩展每 12 小时自动拉一次：官方加线路、下线失效镜像，这边不用换版本就能跟上。 下载前会并发测速，按实测速度 + 历史成功率挑最稳的那条；连挂两次的线路自动冷却。

读取中…

点线路名字可以固定使用它（星标），再点一次恢复自动挑选。

也可以自己加线路：一行一条，格式 名称|https://前缀/，只写前缀也行。不在池子里的域名保存时会弹窗询问授权。

安装到其他浏览器

  • Chrome / Edge / Brave / 360 / QQ 浏览器：打开 chrome://extensions（Edge 是 edge://extensions）， 打开右上角「开发者模式」，点「加载已解压的扩展程序」，选解压出来的文件夹。
  • Firefox：地址栏输入 about:debugging#/runtime/this-firefox， 点「临时载入附加组件」，选中文件夹里的 manifest.json。
  • 换电脑时把文件夹拷过去，重复上面步骤即可，不需要安装包。
