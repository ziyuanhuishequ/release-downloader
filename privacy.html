隐私政策

GitHub Release 下载助手 · 浏览器扩展 v1.4.7 与桌面版 v1.6.9 · 最后更新：2026-11-28

一句话
这个工具不收集、不上传、不出售你的任何数据。所有下载、测速、归档都在你自己的电脑和浏览器里完成， 不需要注册账号，也没有统计代码。

1. 我们不收集什么

  • 不收集姓名、邮箱、手机号等身份信息；
  • 不收集浏览历史、下载记录、IP 地址；
  • 不植入统计 / 广告 / 埋点 SDK；
  • 不读取、不上传你的下载文件内容。

2. 保存在你本地的数据

  • 设置（并发数、线程数、线路偏好、是否归档、可选的 GitHub Token）——存在浏览器的 storage.local（扩展版）或程序同目录的配置文件（桌面版），只有本机能读。
  • 下载记录（哪些文件下过、大小、时间）——用来在列表里显示「已下载」角标，可在设置页一键清除。
  • 线路测速结果（每条加速线路的速度、成功率、冷却时间）——用于下次优先选快的线路。

以上数据都不会离开你的设备。卸载扩展或删除程序目录即全部消失。

3. 会访问哪些网络地址

  • api.github.com：读取 Release 的资源列表（文件名、大小、下载地址）。匿名访问受 GitHub 限流， 可在设置里填自己的 Token 提额，Token 只存在本地。
  • github.com / codeload.github.com / objects.githubusercontent.com： 下载文件本身。
  • 若干公开的 GitHub 加速镜像域名（如 gh-proxy.org、ghproxy.net 等）：下载前并发测速，选最快的一条； 只有你勾选下载时才会访问。
  • raw.githubusercontent.com：读取一份「线路池」JSON（纯 URL 列表），用于增删镜像， 不含任何可执行代码。

这些请求只带必要的 HTTP 头，不携带你的任何身份信息；镜像服务方可能按其自身政策记录访问日志，这点我们无法控制。

4. 「GitHub 国内访问」开关

这是可选功能，默认关闭。打开后，扩展用 declarativeNetRequest 把 github.com 的网页浏览请求重定向到你选中的镜像站点，让你在没有代理的情况下也能看仓库页。 它不代理下载流量、不修改页面内容、不接管登录状态；登录 / 设置类页面不会被重定向。

5. 桌面版（Windows / macOS）

桌面版是单文件程序，不写注册表、不装服务、不联网上报。缓存与配置放在程序同目录或系统缓存目录 （macOS 为 ~/Library/Caches/GitHubReleaseDownloader/），删除即清除。 检查更新时只会向 GitHub 查询一次最新版本号。

6. 第三方

本工具不使用任何第三方分析、广告或数据服务。GitHub 与各加速镜像的隐私实践适用其各自的政策。

7. 儿童隐私

本工具不是面向儿童的产品，也不会有意收集儿童信息（事实上不收集任何人的信息）。

8. 政策变更

如果未来功能变化导致数据处理方式改变，会先更新本页面并修改上面的「最后更新」日期； 涉及收集数据的功能一定默认关闭并单独征得同意。

9. 联系方式

问题、建议或数据相关请求，请到项目仓库提 Issue： github.com/ziyuanhuishequ/release-downloader/issues
