# ===== GitHub 加速线路（自定义）=====
# 一行一条，格式：  名称|前缀      或者直接写前缀
# 前缀必须是 http:// 或 https:// 开头；末尾的 / 会自动补上。
# 以 # 开头的行是注释，会被忽略。
#
# 软件会把这个文件里的线路和内置的 20 条放在一起测速，
# 能用的排到前面，不能用的自动沉底，不会影响别的线路。
# 镜像换域名、或者你有自己搭的加速服务，写在这里就能用，不用等软件更新。
#
# 写完保存，重开软件（或点右上角「重新测速」）生效。
# 想确认有没有被读到：在命令行执行  GitHub下载整理工具.exe --routes
#
# ---- 例子（把前面的 # 去掉，换成你真能打开的地址）----
